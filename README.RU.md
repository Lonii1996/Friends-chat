# Friends Chat Server (Real-time Backend)  [Read in English](README.md)

Проект представляет собой бэкенд для мессенджера реального времени. Написан на платформе .NET с упором на производительность, бинарную сериализацию сетевого трафика и безопасную работу с данными.

Примечание: Входящий в состав репозитория клиент на .NET MAUI разработан исключительно в качестве легковесного визуализатора (UI-клиента) для демонстрации работы API и SignalR-хаба в реальном времени.

## Ключевые архитектурные решения и оптимизации

* **Протокол MessagePack:** Для real-time обмена через SignalR стандартный JSON заменен на бинарный протокол MessagePackProtocol. Это минимизирует размер сетевых пакетов и снижает нагрузку на CPU при сериализации.
* **Cursor-based Пагинация:** Загрузка истории сообщений реализована через курсоры (cursorMessageId) вместо классического Skip/Take. Это гарантирует отсутствие дубликатов и пропусков при бесконечном скролле в условиях постоянно растущей базы данных.
* **Регистронезависимая авторизация:** На уровне PostgreSQL подключено расширение citext для уникальных индексов пользователей. Ники User и user распознаются как один аккаунт, предотвращая коллизии при регистрации.
* **Современный Error Handling:** Обработка ошибок вынесена в глобальный GlobalExceptionHandler (интерфейс IExceptionHandler) с формированием ответов по стандарту RFC 7807 (ProblemDetails).
* **Инфраструктура как код:** Настроен файл docker-compose с автоматическим накатом EF-миграций при старте контейнера сервера и встроенным healthcheck для PostgreSQL.

## Технологический стэк

* **Backend:** .NET 10, ASP.NET Core Web API, SignalR, Entity Framework Core (PostgreSQL), Serilog, xUnit / Moq.
* **DevOps и DB:** Docker, Docker Compose, PostgreSQL 16 (Alpine).
* **UI-Визуализатор:** .NET MAUI (Windows / Android).

## Быстрый запуск (Docker)

Для поднятия бэкенда и базы данных из коробки выполните следующие шаги:

1. Создайте в корневой директории файл .env:
   ```env
   DB_PASSWORD=your_secure_password
   JWT_SECRET_KEY=your_super_secret_jwt_key_at_least_32_chars
   ```
2. Выполните команду:
   ```bash
   docker compose up --build
   ```

После этого:
* Сервер начнет принимать запросы на http://localhost:8080.
* Интерактивная API-документация (Scalar) доступна в режиме разработки по адресу: http://localhost:8080/scalar/v1.

## Запуск UI-клиента (Для тестирования)

Клиент написан на .NET MAUI и автоматически переключает базовый адрес в зависимости от платформы: http://10.0.2.2:8080 для Android-эмулятора и http://localhost:8080 для Windows.

1. Откройте ChatServer.slnx в Visual Studio 2022.
2. Запустите проект ChatClient (выбрав Windows Machine или эмулятор).
3. Используйте встроенную форму для регистрации и авторизации.
